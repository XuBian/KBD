We provide detailed scripts for the scRNA-seq analyses performed in this study.

data integration.R: Contains scripts for scRNA-seq data integration, and marker gene identification.

roe and GO.R: Contains scripts for cell population enrichment analysis, Gene Ontology (GO) enrichment analysis, and visualization.

celltype DE analysis.R: Contains scripts for cell type-specific differential expression analysis and visualization.

metabo analysis.R: Contains scripts for correlation analysis of metabolism-related genes, metabolic activity analysis, and visualization.

cell death analysis.R: Contains scripts for AddModuleScore calculation, correlation analysis between cell death pathways and potential inducers, and visualization.
